## 1. 决策已定，实施者不再按evaluation重新选模型

| 位置 | 固定选择 | 页面含义 |
|---|---|---|
| 标准模式：真假检测 | D-OpenCLIP，官方ViT-L/14 QuickGELU冻结视觉编码器 + 30轮二分类头；固定阈值0.5 | “AI生成倾向”或“真实图片倾向”；显示模型检测分数 |
| 标准模式：来源候选 | A0 ResNet50 22类最终权重；默认Top3，可展开全部22类 | 检测成功且原始p_ai>=0.5时自动运行；是条件来源排序 |
| 标准模式：未知拒识 | 不启用 | unknown.status=unavailable、score=null，提示“尚无经验证的通用未知来源拒识能力” |
| 标准模式：融合/自动切换 | 不启用 | 不自动平均不同检测器、按人脸切模型或使用页面样本选权重/阈值 |
| 研究模式 | 单独选择已登记的对照方法或查看已保存报告 | 不覆盖标准结果；明确任务、标签空间、分数语义与覆盖损失 |

选择依据：
- 同2310张检测evaluation（979真实+1331AI），OpenCLIP AUROC99.8908%、FPR@0.5 1.9408%、TPR98.9482%，优于本次比较中的OmniAID、ConvNeXt和DINOv2。选的是clean模型，不是专门排除FFHQ训练的实验权重。
- A0在同1331张AI evaluation上Top1 77.1600%、Top3 92.9376%。采用它是基于已有接入约定、单模型结构和可追溯产物的工程选择；A0父dev参与过选模，不能称独立测试优胜者。
- 固定50/50分数融合Top1 79.1886%，calibration选出的75/25为77.6108%，但需要额外RGB/指纹分支，尚无在线耗时验收。它们留研究模式；不能因为50/50在evaluation更高而改选权重或宣称严格独立优胜。
- DNA冻结来源头Top1 70.0225%，比同role的OpenCLIP来源头高12.55pp，原group95%区间[9.20,15.92]pp，是优先研究对照。OmniDFA线性58.0766%，相对OpenCLIP的差异区间跨0。
- OFA20+1虽拒绝63/63未知图，却仅保留58/1212已知图（4.7855%），正确且保留仅28/1212（2.3102%）。不作为默认拒识或默认来源模型。

证据为已封口的[实验总览](image_research_results/2026-10-30T0444Z-final/README.md)及overview.json、配对区间和各run/provenance。默认选择不意味着新上传图片具有上述性能保证。

## 3. 四页与标准用户流程

### 文本检测
保留原文本输入、已支持文档上传、分块证据、阈值与报告。文本和图片分别渲染；图片不继承文本的分块、低高双阈值、家族推断或LLM分析。

### 图片检测
桌面双列：左侧上传/预览/文件信息，右侧操作/状态/结果；小屏纵向排列。标准模式只保留上传、开始分析、清空和导出，不要求用户选骨干、设备或阈值。

状态流程：空态 → 文件校验 → 可提交 → 分析中 → 成功/部分成功/失败。没有真实后端进度时只显示spinner、当前真实阶段和已用时间，禁止18/42/78等伪进度、虚构ETA。

首版输入约束（产品限制，可在服务端配置；不是实验参数）：
- 仅静态8-bit JPEG/PNG；RGB或灰度L，灰度按原方法转换RGB。
- 原文件<=10MiB；总像素<=16,000,000；单边<=8192；宽高均>0。
- 拒绝多帧、损坏、16-bit/HDR/CMYK/调色板/透明通道；EXIF orientation只接受缺省或1。给出“请先转为方向正确的不透明RGB JPEG/PNG”的可操作说明。
- 不自动旋转、透明叠底、色彩管理、增强/去噪或重新JPEG压缩后仍声称原预处理。后续扩格式需独立decode_policy版本与测试。
- 后端复核真实文件格式、模式、解压像素数和字节上限，不能仅依赖扩展名或前端限制。预览使用与解码策略一致的像素，注明模型随后会中心裁剪。

结果呈现：
1. 检测结论、原始模型分数的百分比显示、固定阈值0.5、模型版本。
2. 当检测达到阈值：来源Top3及固定说明：
   > 在图片属于AI生成、且来源属于已知22类的条件下，以下标签是模型的候选排序。
3. 当检测低于阈值：来源状态skipped，不自动展示归因；可进入研究模式明确查看上述假设下的排序。不得把“未运行来源模型”写成“已验证未知来源”。
4. 结论使用“倾向”，不能写“100%鉴定”“已证明某服务生成”。来源标签按checkpoint精确class map，不能推测商业服务实际版本或架构家族。
5. 检测失败：不输出真人结论，不运行自动来源链；显示原因和重试入口。检测成功、来源失败：保留检测，整体partial，来源为空并说明。
6. 技术详情折叠显示模型ID、SHA、版本、预处理、实际设备类别、耗时、限制；普通报告不暴露服务器绝对路径、凭据或签名URL。

数字展示必须在完整精度判定后格式化。Top3保留原22类softmax值，不将Top3重新归一化到100%。分数接近阈值时不虚构经过校准的“置信区间”或额外灰区；本版未标定新的灰区阈值。

导航往返保留本会话输入与结果；更换文件即失效旧结果；迟到响应只有在request_id与当前输入SHA仍匹配时才可展示，不能把A图结果显示在B图下；只在用户显式提交时推理。按钮禁用防重复；超时、刷新、控件rerun不自动重跑。清空清理本会话上传缓存，不卸载共享的只读模型，也不触发模型重新加载。

### 实验对照
只读取封口的聚合JSON/CSV。按“真假检测、22来源分类、未知拒识、OFA配对验证”分组；额外区分clean和held-FFHQ、完整dev与evaluation。显示n、训练范围、实际epochs/选模epoch、阈值来源、指标与局限。

相同ID的提升和区间直接引用配对报告；不同分母不画提升箭头。页面不能重选alpha/阈值、重训、下载或重新推理数据集。表格筛选、排序和图表交互仅操作聚合结果。

### 历史报告
按时间/模态/状态筛选，列表分页；查看当时的完整结果、模型/预处理/阈值版本，导出JSON/Markdown。切换默认模型不重算历史。默认只保存结果和必要元数据，不持久化原图；会话预览中的图像在清空/会话结束后回收。

当前项目未建立已核验的多租户鉴权隔离，首版为受控单用户预览，不把“Streamlit会话内不串图”描述成完整账户权限系统。

## 4. 研究能力的明确分级

| 研究组 | 方法 | 必须提示 |

| 来源对照 | DNA LP22、ConvNeXt LP22、OmniDFA LP22/K10、OpenCLIP LP22/KNN、RGB/FP/A-Fusion | 固定已知22类；原型/KNN epoch=null；不同训练/支持预算，不能用一个总分混排所有实验 |
| 分数融合 | 固定50/50、calibration拟合75/25（ResNet/A-Fusion） | 固定公式和类别顺序，不在线拟权重；不是RGB+FP特征融合本身 |
| OFA配对验证 | 冻结原配对头、100个train参考/来源 | 原始配对匹配分数，不能归一化后冒充来源概率；参考库固定，不能用上传图补库 |

## 5. 实验卡片必须保留的事实

- 同225张held-FFHQ（93真实+132AI）：OpenCLIP固定0.5误报15/93=16.13%，ResNet/ConvNeXt各56/93=60.22%。OpenCLIP相对ResNet FPR差值−44.09pp，原group95%区间[−54.77,−33.03]pp。
- 只用非FFHQ calibration真实图按目标1%选阈值：OpenCLIP在FFHQ仍误报7/93=7.53%，Wilson95%约3.69–14.73%；不能显示“实际误报率1%”。
- 同1275 open20 evaluation（1212known+63grok3）：ResNet MSP未知误接收4/63、已知保留47.52%；OFA20+1为0/63、已知保留4.79%，后者不构成实用拒识改善。
- OFA20+1未知AUROC43.38%、OSCR21.70%；0/63误接收的Wilson95%上界仍约5.75%，不能声称未知误接收恒为0。
- 全部是单seed、已看过的开发角色，部分父dev参与选模；实际187–200/生成小格、隔离179新增冲突图、预训练重叠未知。未推理19294张holdout。不要用“SOTA”“独立测试”“生产可用”概括。

## 6. 视觉与交互规范

白底、黑色正文、蓝色强调；红色仅异常等特殊状态。使用开源图标，不使用emoji。先任务和结果，再展开证据与技术参数。来源候选用紧凑条形图/表格；真假分数与来源分数分开，禁止假热力图、AI区域框和由LLM编造的视觉证据。

页面元素纳入出现、状态过渡和退出规范，按钮提供hover轻微缩放、按下、焦点、禁用反馈；结果切换保持容器尺寸稳定，动效约180–240ms并支持prefers-reduced-motion。Streamlit无法保证任意DOM的真实Morph；实现者应记录原生控件无法控制的退出场景，提供稳定布局/淡入淡出替代，不用脆弱DOM注入或另起前端框架来伪造承诺。长操作不使用循环动画遮掩真实错误。
