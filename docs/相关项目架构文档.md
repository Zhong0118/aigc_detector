# AIGC Detector 项目说明与运行文档

这个项目是一个多模态 AIGC 检测与溯源系统，可以对文本、图片、音频、视频进行 AI 生成风险检测，并输出检测分数、来源线索、溯源信息和中文解释报告。

项目包含两个主要入口：

- 后端接口：FastAPI，默认端口 `8000`
- 前端页面：Streamlit，默认端口 `8501`

## 1. 当前模块

### 1.1 后端 API 模块

目录：`api/`

主要文件：

| 文件                 | 作用                                           |
| -------------------- | ---------------------------------------------- |
| `api/main.py`      | FastAPI 后端入口，启动服务并初始化数据库       |
| `api/routes.py`    | 定义接口，例如文本分析、文件分析、报告查询     |
| `api/analysis.py`  | 核心分析流程，串联读取、检测、溯源、报告和入库 |
| `api/dashboard.py` | Streamlit 前端页面                             |

### 1.2 内容读取模块

目录：`ingestion/`

功能：

- 判断上传内容类型：文本、图片、音频、视频
- 读取文件内容
- 提取元数据
- 生成内容指纹

主要文件：

| 文件               | 作用                                     |
| ------------------ | ---------------------------------------- |
| `loader.py`      | 判断文件类型并读取内容                   |
| `metadata.py`    | 提取文件大小、扩展名、图片信息等         |
| `fingerprint.py` | 生成文本 hash、图片感知 hash、音视频指纹 |

### 1.3 AIGC 检测模块

目录：`detection/`

功能：

- 调用外部检测 API
- 调用本地文本检测模型
- 汇总多个检测分支的分数
- 输出最终 AI 风险分数和标签

主要文件：

| 文件                  | 作用                                                             |
| --------------------- | ---------------------------------------------------------------- |
| `providers.py`      | 当前主检测入口，负责 Hive、Sightengine、本地模型和 demo provider |
| `text_detector.py`  | 本地文本 AIGC 检测                                               |
| `image_detector.py` | 图片检测相关代码                                                 |
| `audio_detector.py` | 音频检测相关代码                                                 |
| `video_detector.py` | 视频检测相关代码                                                 |
| `fusion.py`         | 多分支分数融合                                                   |

当前配置里已经包含：

- Hive 检测分支
- Sightengine 检测分支
- 本地文本检测模型
- demo provider

### 1.4 溯源与归因模块

目录：`provenance/`

功能：

- 检查 C2PA 内容凭证
- 检查水印信号
- 查询或记录内容指纹
- 给出候选来源模型 Top-K

主要文件：

| 文件                        | 作用                           |
| --------------------------- | ------------------------------ |
| `pipeline.py`             | 溯源总流程                     |
| `c2pa_reader.py`          | C2PA 读取                      |
| `watermark_decoder.py`    | 水印检测                       |
| `metaseal_adapter.py`     | Meta Seal / VideoSeal 相关适配 |
| `attribution.py`          | 来源归因                       |
| `fingerprint_registry.py` | 指纹库                         |

### 1.5 报告模块

目录：`reports/`

功能：

- 根据检测和溯源结果生成中文报告
- 支持本地模板报告
- 支持调用 LLM 生成解释报告

主要文件：

| 文件             | 作用       |
| ---------------- | ---------- |
| `generator.py` | 报告生成器 |

### 1.6 存储模块

目录：`storage/`

功能：

- 使用 SQLite 保存检测记录
- 保存内容信息、检测结果、溯源记录

主要文件：

| 文件            | 作用               |
| --------------- | ------------------ |
| `database.py` | 数据库连接和初始化 |
| `models.py`   | 数据库表结构       |

默认数据库文件：

```text
data/aigc_detection.db
```

### 1.7 脚本模块

目录：`scripts/`

功能：

- 启动后端
- 启动前端
- 训练文本、图片、音频、视频模型
- 构建来源归因 prototype

常用脚本：

| 文件                                | 作用                 |
| ----------------------------------- | -------------------- |
| `run_api.ps1`                     | 启动 FastAPI 后端    |
| `run_dashboard.ps1`               | 启动 Streamlit 前端  |
| `train_text_attribution.py`       | 训练文本来源归因模型 |
| `train_image_attribution.py`      | 训练图片来源归因模型 |
| `build_attribution_prototypes.py` | 构建来源归因样本库   |

## 2. 当前功能

### 2.1 文本检测

可以直接输入文本，系统会：

1. 判断文本语言和长度
2. 调用检测分支
3. 输出 AI 风险分数
4. 给出候选来源
5. 生成中文解释报告

接口：

```text
POST /api/v1/analyze/text
```

### 2.2 文件检测

可以上传文件，支持文本、图片、音频、视频。

系统会：

1. 判断文件类型
2. 提取元数据
3. 生成内容指纹
4. 执行 AIGC 检测
5. 执行溯源分析
6. 保存结果到数据库
7. 返回检测报告

接口：

```text
POST /api/v1/analyze/file
```

### 2.3 溯源分析

系统会根据检测结果继续做溯源分析，包括：

- C2PA 内容凭证检查
- 水印检测
- 指纹库匹配
- 来源模型候选 Top-K

接口：

```text
POST /api/v1/provenance
```

### 2.4 报告查询

每次分析后会生成 `content_id`，可以通过 ID 查询历史报告。

接口：

```text
GET /api/v1/report/{content_id}
```

### 2.5 前端页面

Streamlit 页面提供：

- 文本输入检测
- 文件上传检测
- provider 状态查看
- 检测分数展示
- 溯源结果展示
- 中文报告展示
- 原始 JSON 查看

访问地址：

```text
http://127.0.0.1:8501
```

## 3. 如何运行

### 3.1 安装依赖

进入项目根目录：

```powershell
cd C:\Users\zx\Desktop\0-Inbox\1-Projects\aigc_detector
```

安装依赖：

```powershell
python -m pip install -r requirements.txt
```

如果已经有可用的 Conda 环境，也可以直接在 Conda 环境里安装：

```powershell
python -m pip install -r requirements.txt
```

## 4. 启动后端

推荐命令：

```powershell
python -m uvicorn api.main:app --host 127.0.0.1 --port 8000
```

启动后访问：

```text
http://127.0.0.1:8000/health
```

如果返回下面内容，说明后端启动成功：

```json
{"status":"ok"}
```

项目里也提供了启动脚本：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_api.ps1
```

注意：`scripts/run_api.ps1` 里面目前写的是本机 Conda Python 路径。如果换到别人的机器，需要把里面的 Python 路径改成对方机器上的 Python 路径。

## 5. 启动前端

后端启动后，再打开一个终端，执行：

```powershell
$env:AIGC_API_BASE="http://127.0.0.1:8000/api/v1"
python -m streamlit run api/dashboard.py --server.address 127.0.0.1 --server.port 8501
```

然后访问：

```text
http://127.0.0.1:8501
```

项目里也提供了启动脚本：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_dashboard.ps1
```

## 6. 配置文件说明

配置文件：

```text
config.yaml
```

常用配置：

| 配置                                            | 说明                                   |
| ----------------------------------------------- | -------------------------------------- |
| `database.path`                               | 数据库路径                             |
| `detection.threshold`                         | AI 判定阈值                            |
| `detection.api_providers.hive.enabled`        | 是否启用 Hive                          |
| `detection.api_providers.sightengine.enabled` | 是否启用 Sightengine                   |
| `detection.local_models.enabled`              | 是否启用本地模型                       |
| `provenance.c2pa.enabled`                     | 是否启用 C2PA                          |
| `provenance.watermark.enabled`                | 是否启用水印检测                       |
| `provenance.attribution.enabled`              | 是否启用来源归因                       |
| `report.provider`                             | 报告方式，支持 `template` 或 `llm` |
| `api.port`                                    | 后端端口                               |
| `dashboard.port`                              | 前端端口                               |

## 7. 最简单的运行顺序

1. 进入项目目录。
2. 安装依赖：`python -m pip install -r requirements.txt`。
3. 启动后端：`python -m uvicorn api.main:app --host 127.0.0.1 --port 8000`。
4. 确认后端正常：打开 `http://127.0.0.1:8000/health`。
5. 启动前端：`python -m streamlit run api/dashboard.py --server.address 127.0.0.1 --server.port 8501`。
6. 打开页面：`http://127.0.0.1:8501`。
7. 输入文本或上传文件开始检测。
