# 资源下载与模型数据准备清单

本文档整理本项目涉及的外部模型、数据集、GitHub 工具和 API 凭证。

## 1. 推荐缓存目录

本项目建议把 Hugging Face 数据集和模型统一缓存到项目目录：

```text
models/huggingface
models/huggingface/hub
models/huggingface/datasets
```

PowerShell 环境变量 配置的是我的当前路径：

```powershell
$env:HF_HOME="$PWD\models\huggingface"
$env:HF_HUB_CACHE="$PWD\models\huggingface\hub"
$env:HF_DATASETS_CACHE="$PWD\models\huggingface\datasets"
$env:TRANSFORMERS_CACHE="$PWD\models\huggingface\hub"
```

如果不设置这些环境变量，Hugging Face 默认会下载到用户系统缓存目录，例如 Windows 下的：

```text
C:\Users\用户名\.cache\huggingface
```

推荐使用项目脚本启动后端：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_api.ps1
```

## 2. Python 依赖

安装基础依赖：此时我的conda环境是dl，里面都是相关的库 比较杂，路径改成自己的即可

```powershell
C:\Users\zx\.conda\envs\dl\python.exe -m pip install -r requirements.txt
```

注意：`transformers==4.x` 需要 `huggingface-hub<1.0`。项目已在 `requirements.txt` 中约束：

```text
huggingface-hub>=0.24,<1.0
```

如果启动时报：

```text
huggingface-hub>=0.19.3,<1.0 is required
```

执行：

```powershell
C:\Users\zx\.conda\envs\dl\python.exe -m pip install "huggingface-hub>=0.24,<1.0"
```

## 3. 检测 API 凭证

### DeepSeek

用途：解释报告增强，不参与核心检测评分。

为了避免费用和 key 泄露，推荐默认使用模板报告：

```yaml
report:
  provider: "template"
```

如果确实需要 LLM 报告：

```yaml
report:
  provider: "llm"
  llm_provider: "deepseek"
  api_key_env: "DEEPSEEK_API_KEY"
  base_url: "https://api.deepseek.com"
  max_tokens: 300
  cache_enabled: true
```

运行前设置：

```powershell
$env:DEEPSEEK_API_KEY="你的 DeepSeek key"
```

## 4. 文本 AIGC 检测模型

### YuchuanTian/AIGC_text_detector

用途：本地文本 AIGC 检测分支，根据中英文、长短文本路由不同模型。

模型来源：

```text
yuchuantian/AIGC_detector_zhv3
yuchuantian/AIGC_detector_zhv3short
yuchuantian/AIGC_detector_env3
yuchuantian/AIGC_detector_env3short
```

触发方式：第一次运行本地文本检测时由 `transformers.from_pretrained(...)` 自动下载。

缓存位置：`models/huggingface`，前提是已设置 HF 环境变量。

## 5. 文本来源归因训练数据

### OpenTuringBench

用途：训练文本来源分类器。

下载类型：Hugging Face 数据集，不是模型权重。

自动下载命令：

```powershell
$env:HF_HOME="$PWD\models\huggingface"
$env:HF_HUB_CACHE="$PWD\models\huggingface\hub"
$env:HF_DATASETS_CACHE="$PWD\models\huggingface\datasets"

C:\Users\zx\.conda\envs\dl\python.exe scripts\train_text_attribution.py --dataset openturingbench --max-samples 30000 --max-per-label 3000
```

输出训练产物：

```text
models/attribution/text_source_classifier.joblib
```

当前推荐主线：

```text
OpenTuringBench + 字符级 TF-IDF + LogisticRegression
```

### 自定义 JSONL

用途：补充 DeepSeek、ChatGPT、Claude、Kimi、文心、Qwen 等来源类别。

文件示例：

```text
data/attribution/text/custom_text_sources.jsonl
```

格式：

```jsonl
{"model":"deepseek","text":"这里放 DeepSeek 生成的文本。"}
{"model":"chatgpt","text":"这里放 ChatGPT 生成的文本。"}
{"model":"kimi","text":"这里放 Kimi 生成的文本。"}
```

训练命令：

```powershell
C:\Users\zx\.conda\envs\dl\python.exe scripts\train_text_attribution.py --dataset openturingbench --extra-jsonl data\attribution\text\custom_text_sources.jsonl --max-samples 30000 --max-per-label 3000
```

## 6. 图片来源归因训练数据与 CLIP

### Tiny-GenImage

用途：训练图片来源分类器。

下载类型：Hugging Face 数据集。

主线方法：

```text
Tiny-GenImage + CLIP image embedding + LogisticRegression
```

训练命令：

```powershell
$env:HF_HOME="$PWD\models\huggingface"
$env:HF_HUB_CACHE="$PWD\models\huggingface\hub"
$env:HF_DATASETS_CACHE="$PWD\models\huggingface\datasets"

C:\Users\zx\.conda\envs\dl\python.exe scripts\train_image_attribution.py --dataset tiny-genimage --feature-extractor clip --max-samples 10000 --max-per-label 1000
```

输出训练产物：

```text
models/attribution/image_source_classifier.joblib
```

### CLIP

用途：提取图片 embedding。

模型：

```text
openai/clip-vit-base-patch32
```

触发方式：图片来源分类训练或推理时自动下载。

缓存位置：`models/huggingface/hub`。

### 本地图片目录

如果不用 Tiny-GenImage，也可以按模型来源分目录：

```text
data/attribution/image_samples/

    001.png
  stable-diffusion-xl/
    001.jpg
  dalle/
    001.png
```

训练命令：

```powershell
C:\Users\zx\.conda\envs\dl\python.exe scripts\train_image_attribution.py --dataset image-folder --input data\attribution\image_samples --feature-extractor clip
```

## 7. C2PA 工具

### c2patool

用途：读取 C2PA 内容凭证。

下载类型：需要手动下载 Windows 可执行文件。

推荐放置路径：

```text
tools/c2patool/c2patool.exe
```

配置：

```yaml
provenance:
  c2pa:
    enabled: true
    mode: "local"
    tool_path: "tools/c2patool/c2patool.exe"
```

说明：

```text
C2PA 只有在文件本身携带内容凭证时才会返回有效信息。
未检测到 C2PA 不等于内容一定是人工创作。
```

### VideoSeal

用途：图片/视频水印检测。

安装方式取决于当前官方仓库和包状态。项目配置中使用：

```yaml
provenance:
  watermark:
    image:
      provider: "videoseal"
      package_root: "third_party/videoseal"
      model: "videoseal"
    video:
      provider: "videoseal"
      package_root: "third_party/videoseal"
      model: "videoseal"
```

需要先在github上下载下来：

```text
部署前先在本机安装/克隆 VideoSeal，并确认权重已缓存。
```

## 9. LLMDet

当前状态：实验分支，默认关闭。

原因：

```text
LLMDet 会下载体积很大的 n-gram probability 数据，曾触发约 4.82GB 下载。
其 PyPI 包和数据缓存也存在版本不一致问题。
```

配置建议：

```yaml
provenance:
  attribution:
    text:
      providers:
        llmdet:
          enabled: false
```

不要在前端检测时自动触发 LLMDet 下载。

## 11. 启动服务

后端：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_api.ps1
```

前端：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_dashboard.ps1
```

不要使用：

```powershell
python -m uvicorn api.main:app --reload
```

原因：

```text
--reload 会监听整个项目目录。Hugging Face 下载缓存、训练产物和测试文件变化会触发后端反复重启。
```

## 12. 最小可运行资源组合

```text
1. requirements.txt 依赖安装完成
2. Hive / Sightengine key 配好，或保留已有检测分支
3. report.provider = template
4. c2patool.exe 放到 tools/c2patool/c2patool.exe
5. text_source_classifier.joblib 已训练或随项目提供
6. image_source_classifier.joblib 已训练或随项目提供
7. LLMDet 关闭
```
