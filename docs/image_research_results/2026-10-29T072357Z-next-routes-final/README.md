# 200张版新视觉路线实验结果

全部注册计算与保存结果验收通过。使用200-q179版63,821张有效图片，保留原始64,000张及179张隔离证据。四个可训练OpenCLIP线性头各30轮；OmniAID冻结验证和KNN没有训练epoch。原holdout没有推理、评分或调参。

OpenCLIP的开发集AUROC提升0.2761个百分点，配对原group bootstrap 95%区间[0.1386,0.4218]；TPR提升2.7047个百分点，区间[1.4448,4.1047]。整体FPR差异区间[-2.4517,0]个百分点到达0，不能宣称已统计确认整体误报下降。OmniAID在这一开发集口径低于项目ResNet对照，不能把冻结外部预训练结果当作本项目30轮训练结果。

FFHQ跨语义对照严格排除FFHQ进入train、selection和calibration。相同225张evaluation含93真实和132 AI：原D2-semantic真实误报56/93（60.22%），新OpenCLIP误报15/93（16.13%）；差异-44.09个百分点，配对group 95%区间[-54.77,-33.03]。AUROC由88.65%升至99.21%，TPR由98.48%至99.24%。该路线仍有明显误报；只在非FFHQ calibration拟合1%/5%目标的阈值，在FFHQ evaluation上实际FPR分别为7.53%/30.11%，不代表目标FPR可跨域保证。

未知calibration固定64张kling，evaluation固定63张grok3；所有方法在calibration误接收均为3/64，阈值没有在evaluation调整。OpenCLIP MSP误接收30/63；原型余弦虽降到4/63，但已知仅保留123/1212，正确且保留81/1212，明显低于原ResNet的576/1212和539/1212。不能只宣传93.65%的未知拒绝率。拒识分数不是未知概率，20类阈值不适用于22类主接口。

选模epoch：D-clean=30、D-held-FFHQ=30、A22=28、open20=29；每个头均完整运行1至30轮。KNN只用train近邻，k由selection MacroF1选定；原型只由已知train特征构造。所有模型均通过实际selection图片的缓存/完整重载/单批一致性检查，阈值容差未放宽。

数值来源说明：calibrated指标绑定linear阶段batch32的保存预测；根目录batch128重算分数最大差约2.4e-7，低于原1e-5验收阈值。held-FFHQ的5%校准点有一张calibration真图决策变化（45/914对46/914），所有evaluation决策保持相同。没有为此重新校准、改容差或重跑模型；两个分数文件的SHA与差异计数同时封口。

独立审查逐项复算六个闭集比较与未知拒识比较，所有1000次原group bootstrap与保存报告完全一致，未知拒识有效重复1000/1000。另见acceptance/verification.json的54项输入哈希、训练历史、模型/角色/配置验收和数值来源。

这些结果来自单seed、已经查看过的开发角色；原父dev参与早期选模，外部模型预训练重叠未知，旧100划分偏差与200新增组修正、187–200实际小格和179隔离仍需保留在解释中。检测与来源任务呈现不同收益，FFHQ残余误报和未知拒识仍是主要局限；没有独立外部测试或生产可用性结论。

模型、图片、数据集、特征缓存和逐图大预测均未纳入Git。完整模型输出和日志路径由snapshot.json及各provenance绑定；旧模型、resolved配置和所有失败证据保留。
