# 文本漏检修复与对照评测

**目标：** 修复分类器静默截断，复用已缓存且有来源标签的数据，实测是否需要换模型或训练。

**已确认的方案：** 保留句子窗口和字符坐标；窗口内部按各模型 token 上限完整推理，以有效 token 数加权。评测比较原实现、修复后 mean、修复后 max、修复后主导语言路由。生产阈值不根据单篇漏检样本调整。用户样本只作独立回归，不用于校准。

**约束：** 不增加依赖、不上传用户文本到第三方、不修改无关文件；训练和正式发布以评测证据为依据。修复改变分数协议，旧阈值的指标不能直接沿用。

## 任务

- [x] `tests/test_text_detector_routing.py`：用本地词表和最小分类器复现尾部丢失及模型 token 上限，先失败再修复 `detection/text_detector.py::_run_model`。
- [x] `scripts/evaluate_text_detector.py`、`tests/test_text_detector_evaluation.py`：读取现有规范化 JSONL；按来源问题分组隔离真人校准与测试，去重，报告 AUROC、召回率、误报率、混淆矩阵和来源分组；比较四个策略，不自动发布阈值。
- [x] 在 school 隔离目录跑现有缓存数据和报告 98 原文，保存采样清单、逐条结果、模型版本及汇总；执行相关及全量测试。
- [x] 根据结果写出训练/换模型/维持策略的结论与复现实验命令，明确样本规模和泛化限制。

## 重点检查

尾部信号不能丢失；模型上限低于配置时仍不溢出；同题真人/AI 样本不能跨校准与测试；重复文本不能重复计分；缺少某类或推理失败时不能伪造指标。
